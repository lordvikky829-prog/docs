Google Workspace is a collection of browser-based productivity tools — Docs, Sheets, Slides, and Forms — that let you create, edit, and collaborate on content with anyone, from any device. Changes save automatically and every edit is tracked in version history.

## Google Docs

Docs is a word processor for writing reports, letters, notes, and any document that requires rich text.

**To create a new document:**
1. Go to [docs.google.com](https://docs.google.com).
2. Click **Blank** or choose a template from the gallery.
3. Start typing — Docs saves automatically to Google Drive.

**Key features:**
- **Suggesting mode** — track changes and leave comments without modifying the original text directly (View → Suggesting).
- **@-mentions** — type `@` to mention a person, file, or date inline.
- **Version history** — File → Version history → See version history to browse and restore earlier versions.
- **Offline editing** — enable offline access in Drive settings to edit without internet.

## Google Sheets

Sheets is a spreadsheet application for data, calculations, and visualisations.

**To create a new spreadsheet:**
1. Go to [sheets.google.com](https://sheets.google.com).
2. Click **Blank** or choose a template.

**Key features:**
- **Formulas** — supports over 400 functions including `VLOOKUP`, `IMPORTRANGE`, and `QUERY`.
- **Charts** — highlight a data range and click Insert → Chart to create bar, line, pie, and other chart types.
- **Conditional formatting** — highlight cells automatically based on rules (Format → Conditional formatting).
- **Data validation** — restrict cell input to specific values or ranges (Data → Data validation).

## Google Slides

Slides is a presentation tool for building slide decks.

**To create a new presentation:**
1. Go to [slides.google.com](https://slides.google.com).
2. Click **Blank** or select a theme.

**Key features:**
- **Themes** — apply a consistent colour scheme and font pairing across all slides.
- **Speaker notes** — add presenter notes below each slide (View → Show speaker notes).
- **Present mode** — click the **Present** button to display your slides full-screen with a presenter view.
- **Publish to web** — File → Share → Publish to web to embed a live presentation on any webpage.

## Google Forms

Forms lets you build surveys, quizzes, and data collection forms.

**To create a form:**
1. Go to [forms.google.com](https://forms.google.com).
2. Click **+** to start a blank form or choose a template.
3. Add questions, sections, images, and videos.
4. Click **Send** to distribute via email, link, or embed code.

Responses appear in a live summary and can be exported to Google Sheets for deeper analysis.

## Real-time collaboration

All Workspace apps support real-time collaboration:

1. Open a file in Docs, Sheets, or Slides.
2. Click **Share** (top-right).
3. Enter email addresses or create a shareable link.
4. Choose a permission level: **Viewer**, **Commenter**, or **Editor**.
5. Click **Send** or **Copy link**.

Collaborators see each other's cursors and edits live. Use the **Comments** sidebar (Ctrl+Alt+M / Cmd+Option+M) to leave feedback without changing the document content.

<Tip>
  Workspace files live in Google Drive. Organise them into shared folders so your team always has access to the right files.
</Tip>
