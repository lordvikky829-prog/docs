A well-organised Drive makes it easy to find files quickly and share the right content with the right people. This guide walks you through the most effective ways to structure your Drive.

<Steps>
  <Step title="Create a folder structure">
    Plan a hierarchy before you start uploading. A common structure works by project or department at the top level, then by date or category inside each folder.

    To create a folder:
    1. Click **+ New → Folder** in Drive.
    2. Type a descriptive name and click **Create**.
    3. Drag existing files into the folder, or click **+ New → File upload** when inside the folder to upload directly to it.
  </Step>

  <Step title="Colour-code your folders">
    Colour coding makes it easier to spot high-priority folders at a glance.

    1. Right-click a folder.
    2. Select **Organise → Change colour**.
    3. Pick a colour from the palette.
  </Step>

  <Step title="Star important files">
    Starred files appear in the **Starred** section of the left sidebar for instant access.

    - Right-click any file or folder and select **Organise → Add to Starred**.
    - Or click the star icon that appears when you hover over a file.
  </Step>

  <Step title="Use shortcuts instead of duplicating files">
    If a file belongs to multiple projects, create a shortcut instead of copying it. A shortcut points to the original — edits appear everywhere automatically.

    1. Right-click the file.
    2. Select **Organise → Add shortcut to Drive**.
    3. Choose the destination folder for the shortcut.
  </Step>

  <Step title="Move files to the correct location">
    - Right-click a file and select **Organise → Move**.
    - Navigate to the destination folder and click **Move here**.

    You can also drag files between folders in the Drive sidebar.
  </Step>
</Steps>

## Shared drives

Shared drives are team-owned storage spaces where all members have access to files even if the person who created a file leaves your organisation. To create a shared drive:

1. Click **Shared drives** in the left sidebar.
2. Click **+ New** and enter a name.
3. Add members and assign permission levels (Manager, Content manager, Contributor, Commenter, or Viewer).

<Note>
  Shared drives are available on Google Workspace plans. Personal Google accounts use "Shared with me" for files others have shared.
</Note>

## Search tips for finding files fast

Use Drive's search bar and filter options to locate any file:

- Click the search bar and use **Search options** (the slider icon) to filter by file type, owner, last modified date, and more.
- Type keywords that appear inside documents — Drive indexes content, not just file names.
- Use `type:folder` or `type:spreadsheet` in the search bar to narrow results by file type.

<Tip>
  Give files descriptive names that include project or client names. Generic names like "Final v2" are hard to find later.
</Tip>
