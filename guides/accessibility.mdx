Google builds accessibility features directly into its services to ensure everyone can search, create, and communicate effectively. This guide covers screen reader compatibility, visual adjustments, keyboard navigation, and live captions.

## Screen reader support

Google services support major screen readers:

| Service | Recommended screen reader |
|---|---|
| Chrome browser | ChromeVox (built-in), JAWS, NVDA |
| Google Docs / Sheets / Slides | ChromeVox, JAWS, NVDA |
| Gmail | ChromeVox, JAWS, NVDA |
| Android apps | TalkBack |
| iOS apps | VoiceOver |

**Enable ChromeVox in Chrome:**
- Go to **Chrome Settings → Accessibility → ChromeVox**.
- Or press **Ctrl+Alt+Z** (Windows/Linux) to toggle it on/off.

**Screen reader mode in Google Docs:**
1. Open a Google Doc.
2. Click **Tools → Accessibility settings**.
3. Enable **Turn on screen reader support**.

This activates a richer HTML structure and ARIA labels that help screen readers navigate documents.

## Keyboard shortcuts

All major Google services support keyboard-first navigation.

**Gmail keyboard shortcuts:**
Enable shortcuts in Gmail: Settings → See all settings → General → Keyboard shortcuts → **Keyboard shortcuts on**.

| Action | Shortcut |
|---|---|
| Compose new email | C |
| Reply | R |
| Reply all | A |
| Forward | F |
| Archive | E |
| Search | / |
| Go to inbox | G then I |

**Google Docs shortcuts:**

| Action | Windows / Linux | Mac |
|---|---|---|
| Bold | Ctrl+B | Cmd+B |
| Heading 1 | Ctrl+Alt+1 | Cmd+Option+1 |
| Insert comment | Ctrl+Alt+M | Cmd+Option+M |
| Open shortcut list | Ctrl+/ | Cmd+/ |

## Visual accessibility

**High contrast mode:**
In Chrome, install the [High Contrast extension](https://chrome.google.com/webstore/detail/high-contrast/djcfdncoelnlbldjfhinnjlhdjlikmph) to invert or darken colours across all websites, including Google services.

**Zoom and text size:**
- Press **Ctrl++** (Windows) or **Cmd++** (Mac) to zoom in on any Google page.
- Set a default zoom level in Chrome: Settings → Appearance → Page zoom.

**Dark mode:**
Enable dark mode in the Google app (Android and iOS) via Settings → Theme → Dark.

## Live captions in Google Meet

Meet provides live captions for all meetings, powered by Google's speech recognition.

To enable captions during a meeting:
- Click the **CC (Closed Captions)** button in the Meet controls bar.
- Captions appear at the bottom of the screen in real time.

Captions are available in English, French, German, Portuguese, and Spanish.

## Magnifier (Android)

Android devices include a built-in Magnifier for zooming in on any part of the screen:

1. Go to **Settings → Accessibility → Magnification**.
2. Enable **Magnification shortcut**.
3. Use the shortcut (triple-tap or accessibility button) to zoom in on any content.
